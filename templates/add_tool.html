Add a Tool

A seven-step guide for extending AgentLab. All execution stays on the Django server.

1. Create a Python function

Add a module under agent/tools/. Return a dictionary with success, summary, error, and data.

def execute(city: str) -> dict:
    return {
        "success": True,
        "error": None,
        "summary": f"Looked up {city}",
        "data": {"city": city},
    }

2. Define parameters

Keep arguments explicit and validated. Reject empty values and unexpected types before calling any API.

3. Create a Gemini function schema

{
  "name": "weather",
  "description": "Get current weather for a city.",
  "parameters": {
    "type": "object",
    "properties": {
      "city": {"type": "string"}
    },
    "required": ["city"]
  }
}

4. Register the tool

Export NAME, DESCRIPTION, CATEGORY, SCHEMA, and execute, then add the module to _TOOL_MODULES in agent/services/tool_registry.py.

5. Add execution logic

The agent loop never uses a giant if/elif router. It looks up the tool by name and calls execute_tool(). Timeouts, missing keys, and invalid input should return friendly errors — never stack traces.

6. Test the tool

Use the Tool Playground for direct execution. Add unit tests in agent/tests/. Mock external HTTP so tests do not need live keys.

7. Add a challenge

Teach the new tool by adding a record in seed_challenges with expected_tools set to the new tool name. Run python manage.py seed_challenges.
