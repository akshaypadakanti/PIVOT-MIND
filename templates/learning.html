What is an Agent?

An agent is a language model wrapped in a loop. It can read a user question, decide that it needs outside help, call a tool, read the result, and either call another tool or stop with a final answer.

What is a Tool?

A tool is a Python function with a clear contract: name, description, arguments, and a structured result. Calculator, weather, and web search are tools. The model does not implement them; Django does.

What is Function Calling?

Function calling is the Gemini API feature that lets the model return a structured function name and JSON arguments instead of (or before) a prose answer. AgentLab registers each tool schema so the model can pick one.

What is Tool Calling?

Tool calling is the same idea with the newer tools API. AgentLab uses tool schemas, executes the chosen Python function on the server, and sends the result back to the model.

What is Tool Chaining?

Chaining means the model uses the output of one tool as input to another. Example: weather in Hyderabad → unit converter to Fahrenheit → final sentence. A maximum call limit prevents infinite loops.

Why use a Tool Registry?

The registry is a single catalog of names, schemas, and callables. The agent loop asks the registry “what exists?” and “run this.” Views, the playground, and the developer page all read the same catalog.

Why should tools be modular?

Each tool lives in its own module. Adding a capability should not rewrite routing, templates, or other tools. Modular tools are easier to test, disable, and explain to learners.
